# Grilled Phish — store listing (zh_CN)

## Name

Grilled Phish

## Short description (52/132 characters)

给仿冒知名网站的假链接（如 paypa1.com、pаypal.com）加上红框并拦截，除非你真正确认。

## Full description

Grilled Phish 会给仿冒的山寨链接加上红框并将其拦截，直到你真正确认为止。

骗子几分钟就能复制一个真网站，唯一复制不了的是网址，所以他们会使用几乎一模一样的地址：paypa1.com（数字 1）、pаypal.com（一个俄文字母）、arnazon.com（用“rn”冒充“m”）、paypal.com.secure-verify.xyz。Grilled Phish 替你读懂网址。

• 假链接会被加上红框，点击也打不开。清晰的警告会显示链接真正指向哪里，标出可疑的字母，并列出真网站。
• 在假网页上会出现红色横条，密码和银行卡输入框会被锁住。
• 能识别 10 万个知名网站的仿冒品，而不只是大品牌。
• 像 githhub.com 这样的输入错误，会在网站加载前询问“你是不是想输入 github.com？”。
• 非常新的网站（大多数诈骗网站只存在几天）会收到较温和的提醒。
• 严格模式，适合为父母或祖父母的电脑进行设置。
• 一份 5 分钟的识骗指南。

隐私至上：无需账户，没有服务器，不做跟踪。所有检查都在你的浏览器内完成。Grilled Phish 永远不会联系你：任何自称来自 Grilled Phish 的人都是骗子。

测试版：Grilled Phish 可能漏掉一些诈骗，而且只检查网址（不是内容过滤器，也不是杀毒软件）。请保持浏览器自带的防护处于开启状态。
