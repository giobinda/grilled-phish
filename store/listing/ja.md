# Grilled Phish — store listing (ja)

## Name

Grilled Phish

## Short description (64/132 characters)

有名サイトをまねた偽リンク（paypa1.com、pаypal.com など）を赤い枠で囲み、本当に確認するまでブロックします。

## Full description

Grilled Phish は、本物そっくりの偽リンクを赤い枠で囲み、あなたが本当に確認するまでブロックします。

詐欺師は本物のサイトを数分でコピーできます。コピーできない唯一のものはアドレスなので、ほとんど同じに見えるアドレスを使います。paypa1.com（数字の1）、pаypal.com（ロシア文字）、arnazon.com（「m」の代わりに「rn」）、paypal.com.secure-verify.xyz などです。Grilled Phish があなたの代わりにアドレスを読みます。

• 偽のリンクは赤い枠で囲まれ、クリックしても開きません。わかりやすい警告が、リンクの本当の行き先を、おかしな文字を強調して、本物のサイトと並べて表示します。
• 偽のページでは赤いバーが表示され、パスワードやカード番号の入力欄がロックされます。
• 大手ブランドだけでなく、有名な10万サイトのコピーを見つけます。
• githhub.com のような入力ミスには、サイトが開く前に「もしかして github.com ですか？」と確認します。
• とても新しいサイト（詐欺サイトのほとんどは作られて数日です）には、穏やかな警告を表示します。
• 両親や祖父母のパソコンに設定するための厳格モード。
• 詐欺の見分け方がわかる5分間のガイド。

プライバシー重視：アカウントもサーバーも追跡もありません。すべてのチェックはブラウザーの中で行われます。Grilled Phish からあなたに連絡することはありません。Grilled Phish を名乗る人は詐欺師です。

ベータ版：Grilled Phish は詐欺を見逃すことがあり、確認するのはサイトのアドレスだけです（コンテンツフィルターやウイルス対策ソフトではありません）。ブラウザー自体の保護機能はオンのままにしてください。
