# Grilled Phish — store listing (de)

## Name

Grilled Phish

## Short description (126/132 characters)

Rahmt gefälschte Links, die bekannte Websites nachahmen (paypa1.com, pаypal.com…), rot ein und sperrt sie bis zur Bestätigung.

## Full description

Grilled Phish rahmt gefälschte Doppelgänger-Links rot ein und blockiert sie, bis Sie wirklich bestätigen.

Betrüger kopieren eine echte Website in wenigen Minuten. Nur die Adresse können sie nicht kopieren, deshalb nutzen sie fast gleiche Adressen: paypa1.com (die Ziffer 1), pаypal.com (ein russischer Buchstabe), arnazon.com („rn“ statt „m“), paypal.com.secure-verify.xyz. Grilled Phish liest die Adresse für Sie.

• Gefälschte Links bekommen einen roten Rahmen und öffnen sich beim Klicken nicht. Eine klare Warnung zeigt, wohin der Link wirklich führt, hebt die verdächtigen Buchstaben hervor und nennt die echte Website.
• Auf einer gefälschten Seite erscheint ein roter Balken, und Passwort- und Kartenfelder werden gesperrt.
• Erkennt Kopien von 100.000 bekannten Websites, nicht nur von großen Marken.
• Bei Tippfehlern wie githhub.com fragt es „Meinten Sie github.com?“, bevor die Seite lädt.
• Sehr neue Websites (die meisten Betrugsseiten sind nur wenige Tage alt) bekommen eine mildere Warnung.
• Ein strenger Modus, um es auf dem Computer von Eltern oder Großeltern einzurichten.
• Eine 5-Minuten-Anleitung zum Erkennen von Betrug.

Datenschutz von Anfang an: kein Konto, keine Server, kein Tracking. Alle Prüfungen laufen in Ihrem Browser. Grilled Phish wird Sie nie kontaktieren: Wer behauptet, von Grilled Phish zu sein, ist ein Betrüger.

Beta: Grilled Phish kann Betrug übersehen und prüft nur Webadressen (es ist kein Inhaltsfilter und kein Virenschutz). Lassen Sie den Schutz Ihres Browsers eingeschaltet.
