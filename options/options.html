    🗓️ Brand-new websites

    Most scam websites are created a few days before the attack and disappear soon after. Link Guardian can check when a website was created and block very new ones.

    Privacy: to do this, only the website's name (for example best-deals.shop, never the full address or what you do there) is sent to the official registry for that ending, such as Verisign for .com. Some endings (.it, .de, .es, .eu) don't publish creation dates, so those sites can't be checked.

    ⭐ Well-known websites

    Link Guardian knows the most visited websites in the world, so it can block copies of them (for example wikipedla.org pretending to be wikipedia.org). The check happens on your computer.
