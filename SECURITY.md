# Security

## Reporting a vulnerability

Please report security problems **privately** with GitHub's form:
**Security** tab of this repository → **Report a vulnerability**
(https://github.com/giobinda/grilled-phish/security/advisories/new).

Useful to include: the browser and version, what a hostile web page can do, and a test page or steps.
Please don't open a public discussion before a fix is released.

Things that are in scope include: a web page that hides, removes, fakes or clicks through Grilled Phish's
warnings; a way to make a look-alike address pass; a way to get a tampered list of well-known sites
accepted; anything that leaks what a person visits.

## Grilled Phish never contacts anyone

There is no Grilled Phish email address, phone number, chat or support account. We never write to people,
never ask them to install, remove, disable or "update" anything, and never ask for passwords, codes or money.
**Anyone who contacts you claiming to be Grilled Phish is a scammer.** Our only website is this repository:
https://github.com/giobinda/grilled-phish
