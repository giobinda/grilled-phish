Grilled Phish demo page

Open this page with the extension installed. Fake links should get a red box and be disabled. None of these links go anywhere real.

Should be BLOCKED

  • PayPal with a Cyrillic "а"
  • Log in to PayPal (number 1 instead of l)
  • Your Amazon order ("rn" instead of "m")
  • www.paypal.com.secure-verify.xyz
  • https://www.paypal.com/signin (text lies about the destination)
  • Verifica il tuo conto Poste
  • Track your DHL parcel
  • amazom.com (one letter wrong)

Should be ALLOWED

  • The real PayPal
  • The real Amazon Italy
  • Wikipedia
  • apply.com (a normal word, not Apple)

Copies of well-known websites (database)

  • GitHub sign in (digit 1 hidden in "github": blocked immediately)
  • stackoverfIow.com (capital I instead of l: blocked because the site is brand new)
  • stackoverflow.com.answers-hub.xyz (real address used as a prefix)

Brands' own sites in other countries (should be ALLOWED)

  • google.ru
  • amazon.co.za
  • stackoverflow.com

Brand-new website (blocked by the age check)

  • Huge discounts, today only! (blocked only if the site is less than a month old)
  • Wikipedia: Phishing (created 2001, allowed)
